# مِترا

فضای کار آزمایشی متره و برآورد، بر پایه Next.js و PostgreSQL. کد اولیه از فایل فشرده موجود در مخزن استخراج شده است.

## اجرا

به Node.js 22 و PostgreSQL نیاز دارید. یک پایگاه‌داده خالی بسازید و مقدار اتصال آن را در `.env.local` قرار دهید (نمونه در `.env.example`). سپس:

```sh
npm ci
npm run db:migrate
npm run dev
```

`drizzle-kit` متغیرهای فایل محیطی Next.js را خودکار نمی‌خواند؛ برای دستور migration ابتدا `DATABASE_URL` را در محیط شِل صادر کنید. migration اولیه مخصوص پایگاه‌داده خالی است؛ برای پایگاه‌داده موجود راهنمای Netlify را بخوانید. برای نسخه production از `npm run build` و سپس `npm start` با همان متغیر محیطی استفاده کنید.

## استقرار روی Netlify

راهنمای تنظیم متغیرها، migration پایگاه‌داده خالی، محدودیت‌های Functions، امنیت و چک‌لیست انتشار در [docs/NETLIFY.md](docs/NETLIFY.md) آمده است. این آماده‌سازی به‌تنهایی به معنی انتشار یا تأیید استقرار واقعی نیست.

## آزمون‌ها

`npm test`، `npm run typecheck` و `npm run lint` مستقل از سرور اجرا می‌شوند. برای `npm run test:integration` و `node scripts/security-check.mjs` سرور و پایگاه‌داده باید در دسترس باشند. آزمون مرورگر `npm run test:browser` به Chromium نصب‌شده از طریق Playwright و کتابخانه‌های سیستم نیاز دارد.

## محدودیت‌ها

این نسخه برای نمایش و آزمون است، نه استقرار عمومی یا اتکای مهندسی/حقوقی. قواعد و اسناد رسمی نیازمند بررسی متخصص هستند؛ تعدیل، ضرایب، مالیات و امکانات دیگر کامل نیستند. برای جزئیات امنیت و دامنه محصول به `docs/FINAL_AUDIT.md` مراجعه کنید. داده‌های پیش‌نمایش موقت‌اند و پشتیبان‌گیری دائمی ندارند. گزینه `ARENA_PREVIEW=1` فقط برای نمایش داخل Arena است و سیاست جلوگیری از قاب‌بندی را برای دامنه‌های پیش‌نمایش تغییر می‌دهد؛ آن را در استقرار عمومی فعال نکنید.

### نشست پیش‌نمایش و به‌روزرسانی

در پیش‌نمایش جاسازی‌شده، نشست ابتدا از کوکی Secure و Partitioned استفاده می‌کند. اگر کوکی برگردانده نشود، فقط در حالت پیش‌نمایش، نشست جایگزین در ذخیره‌سازی همان برگه نگهداری می‌شود؛ جزئیات امنیت و محدودیت آن در راهنمای Netlify آمده است. اگر ذخیره‌سازی هم مسدود باشد، نشست فقط در حافظه صفحه می‌ماند و با بارگذاری مجدد از دست می‌رود. نشست برگه مستقل و قاب جاسازی‌شده ممکن است مجزا باشند؛ پیش از جابه‌جایی، برای حفظ داده‌های مهمان حساب بسازید. داده‌های محیط پیش‌نمایش موقتی‌اند.

فضای کار باز هر ۶۰ ثانیه و هنگام بازگشت به برگه بازخوانی می‌شود. این به معنی دریافت خودکار قیمت‌ها، ضوابط یا فهرست‌بهای رسمی نیست: منابع معتبر و تغییرات آن‌ها باید توسط کارشناس بررسی و ثبت شوند. نسخه‌های ثابت برآورد پس از تغییر داده‌های زنده عمداً تغییر نمی‌کنند.

در گزارش زنده، ردیف‌های تأییدشده‌ای که قاعده‌شان نامعتبر شده «نیازمند بازبینی» هستند و در جمع تأییدشده نمی‌آیند. اعداد فراتر از دقت اکسل برای صادرات اکسل رد می‌شوند؛ در برآورد می‌توان از JSON/CSV استفاده کرد. PDF از چاپ مرورگر تولید می‌شود و خروجی Word/DOCX هنوز وجود ندارد.
